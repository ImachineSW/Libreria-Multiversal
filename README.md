# Proyecto-de-Fin-de-A-o-E-Commerce-Bibloteca-
TECNOLOGÍAS FRONT-END
Para el desarrollo de la interfaz del sistema se utilizarán las siguientes tecnologías:
HTML5
Será utilizado para construir la estructura semántica de todas las páginas del sitio web. Permite organizar correctamente el contenido y mejorar la accesibilidad y compatibilidad con los navegadores modernos.
CSS3
Se utilizará para definir el diseño visual del sistema, incluyendo colores, tipografías, distribución de los elementos y diseño adaptable (Responsive Design) para diferentes tamaños de pantalla.
JavaScript
Permitirá agregar interactividad a la aplicación mediante validación de formularios, manipulación del DOM, eventos del usuario y funciones dinámicas que mejoren la experiencia de navegación.
Git y GitHub
Git será utilizado como sistema de control de versiones para registrar los cambios realizados durante el desarrollo, mientras que GitHub permitirá almacenar el repositorio privado y facilitar el trabajo colaborativo entre los integrantes del equipo.
